This repository contains my laboratory assignments, transistor-level circuit schematics, design calculations, and simulation results for the **ITI Analog IC Design** course. 

The focus of these labs spans fundamental MOS device characterization to advanced analog building blocks, emphasizing DC operating point analysis, AC small-signal response, stability, and noise optimization.
